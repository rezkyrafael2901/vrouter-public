Integrations & Tools

Configure your favorite AI tools to use VRouter as the backend. Just change the base URL and paste your API key.

⚡

Cursor

IDE

Use VRouter as a custom OpenAI endpoint in Cursor's AI settings. Works with all models through the Chat, Composer, and Tab features.

// Cursor Settings → Models → OpenAI API Key // Settings → Models → Override OpenAI Base URL Base URL: https://vrouter.my.id/v1 API Key: vr-you...-key
🧠

Claude Code

CLI

Route Claude Code through VRouter by setting the Anthropic base URL environment variable. All Claude models available.

# Set environment variable before launching export ANTHROPIC_BASE_URL=https://vrouter.my.id/v1 export ANTHROPIC_API_KEY=vr-you...-key # Then start Claude Code normally claude
🤖

OpenAI Codex

CLI

Use VRouter with OpenAI Codex CLI by pointing the OpenAI base URL to our endpoint.

# Set environment variable export OPENAI_BASE_URL=https://vrouter.my.id/v1 export OPENAI_API_KEY=vr-you...-key # Run codex with any model codex --model gpt-4o "your prompt"
🔌

Continue.dev

EXT

Configure Continue.dev VS Code / JetBrains extension to use VRouter as the LLM provider via its apiBase config.

// ~/.continue/config.json { "models": [{ "title": "VRouter", "provider": "openai", "model": "gpt-4o", "apiBase": "https://vrouter.my.id/v1", "apiKey": "vr-you...-key" }] }
🔮

Hermes / Aider

AGENT

Use VRouter with Hermes Agent, Aider, or any OpenAI-compatible agent via Bearer token authentication.

# Aider export OPENAI_API_BASE=https://vrouter.my.id/v1 export OPENAI_API_KEY=vr-you...-key aider --model openai/gpt-4o # Hermes Agent export OPENAI_BASE_URL=https://vrouter.my.id/v1 export OPENAI_API_KEY=vr-you...-key

OpenAI-compatible LLM router with 1000+ models across 30+ providers.
