02 Authentication & Keys

Every request requires a valid API key in the Authorization header.

Key format

VRouter keys follow the vr- prefix convention.

# Include in every request header
Authorization: Bearer vr-...here
from openai import OpenAI

client = OpenAI(
    base_url="https://vrouter.my.id/v1",
    api_key="***",  # set automatically as Bearer
)
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://vrouter.my.id/v1",
  apiKey: "***",  // auto-injected as Bearer
});

Header reference

Header Type Required Description
Authorization string Required Bearer token — your VRouter API key
Content-Type string Required Must be application/json
⚠

Key rotation

Rotate keys regularly from your dashboard. Old keys are revoked instantly. Never expose keys in client-side code or public repositories.

POST /v1/chat/completions Auth required

Create a model response for the given chat conversation. Fully OpenAI-compatible.

Request body
Parameter Type Required Description
model string Yes Model ID, e.g. gpt-4o or anthropic/claude-3-5-sonnet
messages array Yes Chat messages with role and content
stream boolean No Enable SSE streaming. Default: false
temperature number No Sampling temperature 0–2. Default: 1
max_tokens integer No Maximum tokens to generate
top_p number No Nucleus sampling. Default: 1
💡

Use provider/model syntax for explicit routing: openai/gpt-4o, anthropic/claude-3-5-sonnet. Or bare gpt-4o for smart auto-routing.

GET /v1/usage Auth required

Retrieve your usage stats: total requests, token counts, and per-model breakdown for the last 24 hours.

04 Streaming

Receive responses token-by-token via Server-Sent Events (SSE). Ideal for real-time UIs.

curl https://vrouter.my.id/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer *** \
  -d '{
    "model": "gpt-4o",
    "messages": [{"role": "user", "content": "Count to 5"}],
    "stream": true
  }' --no-buffer
from openai import OpenAI

client = OpenAI(
    base_url="https://vrouter.my.id/v1",
    api_key="***",
)

with client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "Count to 5"}],
    stream=True,
) as response:
    for chunk in response:
        delta = chunk.choices[0].delta.content
        if delta:
            print(delta, end="", flush=True)
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://vrouter.my.id/v1",
  apiKey: "***",
});

const stream = await client.chat.completions.create({
  model: "gpt-4o",
  messages: [{ role: "user", content: "Count to 5" }],
  stream: true,
});

for await (const chunk of stream) {
  const text = chunk.choices[0]?.delta?.content;
  if (text) process.stdout.write(text);
}

SSE event format

Each chunk is a data: line. The stream ends with data: [DONE].

data: {"choices": [{"delta": {"content": "1"}}]}
data: {"choices": [{"delta": {"content": " "}}]}
data: {"choices": [{"delta": {"content": "2"}}]}
data: {"choices": [{"delta": {"content": " "}}]}
data: {"choices": [{"delta": {"content": "3"}}]}
data: [DONE]

06 Errors

VRouter uses standard HTTP status codes. All errors return a consistent JSON structure.

Error response format 
{
  "error": {
    "message": "Human-readable error description",
    "type": "error_type",
    "code": "machine_readable_code"
  }
}
400 Bad Request

Missing or invalid parameters.

{"error": {"message": "Missing required parameter: model", "type": "invalid_request_error"}}
401 Unauthorized

Invalid or missing API key.

{"error": {"message": "Invalid API key", "type": "authentication_error"}}
403 Forbidden

Account deactivated or key lacks permission.

429 Rate Limited

Too many requests. Implement exponential backoff.

{"error": {"message": "Rate limit exceeded", "type": "rate_limit_error", "code": "rate_limit"}}
503 Service Unavailable

Backend provider temporarily unreachable. VRouter will retry with failover.

07 TypeScript

Full type support via the official OpenAI SDK. VRouter is a drop-in replacement — just change the base URL.

// install: npm install openai
import OpenAI, type { ChatCompletion } from "openai";

const client = new OpenAI({
  baseURL: "https://vrouter.my.id/v1",
  apiKey: process.env.VROUTER_API_KEY,
});

const completion: ChatCompletion = await client.chat.completions.create({
  model: "gpt-4o",
  messages: [
    { role: "system", content: "You are a helpful assistant." },
    { role: "user",   content: "What is the capital of France?" },
  ],
  temperature: 0.7,
});

console.log(completion.choices[0].message.content);

import OpenAI from "openai";
import type {
  ChatCompletionMessageParam,
  ChatCompletionCreateParams,
} from "openai/resources";

const client = new OpenAI({
  baseURL: "https://vrouter.my.id/v1",
  apiKey: process.env.VROUTER_API_KEY,
});

// Typed helper function
async function chat(
  messages: ChatCompletionMessageParam[],
  model: string = "gpt-4o"
): Promise<string> {
  const res = await client.chat.completions.create({
    model,
    messages,
  });
  return res.choices[0].message.content ?? "";
}

// Usage
const reply = await chat([
  { role: "user", content: "Hello!" },
]);
console.log(reply);
